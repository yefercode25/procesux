# ProcesUX

Aplicación Vite + React + TypeScript para explorar y revisar manuales de procesos y procedimientos de forma guiada.

## Cómo usar

```bash
npm install
npm run dev
```

## Qué incluye

- Dashboard por macroprocesos.
- Explorador lateral tipo árbol.
- Buscador y filtros.
- Ficha por procedimiento.
- Revisión paso a paso por actividades.
- Registro de hallazgos con prioridad, tipo y estado.
- Persistencia local con `localStorage`.
- Línea visual ProcesUX con fuente Montserrat, colores institucionales y enfoque GOV.CO/Gachetá.

## Carga de datos

Los datos están en `src/data/manualData.ts`. Puedes agregar más procedimientos siguiendo la misma estructura.
